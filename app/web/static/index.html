How it works

Most detection stacks break ties between overlapping spans by model confidence. This one ranks by evidence class.

  1. 01

    Detect

    Taxonomy regexes find structured identifiers; spaCy NER, via Presidio, finds names and places. Scanners over-match on purpose.

  2. 02

    Validate

    Each candidate runs its type's validator — Luhn, the ABA mod-10 checksum, SSA issuing rules, NANP numbering rules.

  3. 03

    Arbitrate

    Overlaps resolve by tier, then span length, then context-word proximity. Failed checks leave contention entirely.

  4. 04

    Redact

    Survivors are replaced back to front with typed tokens; account numbers keep their last four digits.

Evaluation

Two splits. Tuning documents come from the templates the rules were developed against; held-out documents come from templates never used while tuning. CI fails the build if either regresses.
